# 租车协议交互台账 · 静态演示看板

> 这是一个**数据已脱敏**的静态只读演示版，用于展示看板能力。
> 源码与完整功能见私有仓库。

## 能看什么

- 10 张业务表的结构与数据浏览（租车用户汇总、套餐购买订单列表、财务看板等）
- 数据看板：状态分布、快到期、已欠租、今日开通/退订等统计卡片
- 多维筛选与排序、列顺序调整、导出当前表

## 不能做什么

- ❌ 编辑与保存（静态版无后端，写入会被拦截并提示）
- ❌ 同步数据库 / 重算金额
- ❌ 查看图片（车辆照片、证件图片等均未上传）

## 数据脱敏说明

| 字段类型 | 处理方式 |
|---|---|
| 手机号 | `138****5678` |
| 姓名（用户/导购/推广人） | `张**`、`易**-阳朔` |
| 身份证号 | 整列清空 |
| 车牌 / 车架号 | 部分打码 `粤B***45` |
| 全部图片（含证件照） | 清空，未上传 |

未包含：签约协议明细表（业务明细）、images 目录、服务端脚本原始数据。

## 技术说明

- 纯静态：无任何后端，可托管在 GitHub Pages
- `static-shim.js` 拦截 `/api/*` 请求并映射到 `api/*.json`，实现看板离线可用
- 数据快照时间见 `api/health.json` 的 `sync_version`
